# 賽博雷音

用骨傳導耳機合成「念誦口型」的聲音，調整頻率與頻譜，體驗顱內共振部位的變化；同時保留雙耳節拍（Hemi-Sync）的條件。個人體驗用。

- 規格與邊界條件：[docs/SPEC.md](docs/SPEC.md)
- 背景播放測試頁：[spike/bg-audio/](spike/bg-audio/)（發布到 GitHub Pages 後，用手機開 `https://<帳號>.github.io/<repo>/spike/bg-audio/`）
